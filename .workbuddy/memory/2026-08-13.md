## 修复：插件调用方式 core.plugin.xxx（不是 core.plugin["插件名"]）
### 根因（用户指出正确）
魔塔样板插件 install 用 `(function(){...}).call(plugin)` 挂载 → 所有方法直接挂在 **core.plugin 顶层**（如 core.plugin.boxbar、core.plugin.addBackpackWeapon、core.plugin.openCraftPanel）。plugins.js 的 key（"背包"、"背包乱斗商店"等）只是注册表名字，**不是 core.plugin 的属性**。证据：items.js 用 core.plugin.boxbar() 打开背包。
### 修复
- backpackShop.buyWeapon：core.plugin["背包"] → core.plugin（直接判断 addBackpackWeapon）。
- backpackCraft.getBackpackPlugin：同改 core.plugin。
- backpackSystem 合成按钮：core.plugin["背包乱斗合成"] → core.plugin.openCraftPanel。
- 用户事件脚本正确写法：core.plugin.openBackpackShop() / core.plugin.openCraftPanel()（不是 core.plugin["背包乱斗商店"]）。
- version 2.10.14 → 2.10.15。
### 验证
81 项测试全过。

## 怪物奥义系统
### 需求
怪物也做奥义：怪物配置奥义获取词条；怪物奥义受 debuff 影响；奥义发动=立刻攻击2次（奥义攻击不获取奥义、正常触发 buff/debuff）。

### 实现
- rules.createSide 加 ultimateGain 字段；getUltimateGain(side,...) 本就支持按目标方状态计算（高扬+2/层、虚脱-2/层）→ 传 state.enemy 天然"受 debuff 影响"。
- backpackBattle.getEnemySnapshot 加 ultimateGain（读 core.material.enemys 怪物的 ultimateGain 字段，getEnemyValue 支持楼层覆盖）。
- core.attackEnemy(options)：普通攻击后若 ultimateGain>0 → ultimate += getUltimateGain(enemy,...)；奥义攻击 options.gainUltimate=false 不获取；afterHit 的 attackOrigin 区分 normal/ultimate。
- core.resolveEnemyUltimate：奥义≥100 → 扣100 → attackEnemy×2（gainUltimate:false）→ afterEnemyUltimate 规则钩子；guard 防死循环。
- estimate kernel：敌方攻击后按期望累计奥义，满100发动 → 额外2次攻击期望伤害。
### 配置（怪物定义 enemys.js 加字段）
"ultimateGain": 40  （每攻击一次获取40点奥义，满100发动）
### 验证
- 30×3=90 不发动✓；40×3=120→发动剩20+2次额外攻击(承伤250)✓；虚脱3层→34×3=102→发动剩2✓（debuff影响）；无词条不获取✓。81项测试全过。

## 批量给怪物配置 attackInterval / ultimateGain（enemys.js）
### 需求
所有已填攻防血数据的怪物（000 视为没填）补攻击间隔与奥义获取，参照攻防血平衡。
### 规则（按 atk 阶梯 + hp 修正）
- attackInterval（越大越慢）：atk<60→1.0, <120→1.2, <250→1.4, <450→1.6, <800→1.9, ≥800→2.3；hp≥2000 +0.3。
- ultimateGain（越大奥义越快）：atk<60→0(杂兵无奥义), <120→15, <250→22, <450→30, <800→38, ≥800→45。
- 已有 attackInterval/ultimateGain 的怪物保留原值不覆盖。
### 实现
- python 脚本：正则找 "id":{ + 栈匹配花括号（支持跨行/嵌套 faceIds）→ JSON 解析 → 计算插入字段。
- 踩坑：①out.append 丢 key 前缀；②finditer 会匹配嵌套 faceIds 导致重复输出（需 if m.start()<pos: continue）。已备份回滚修复。
### 结果
80 只怪物：58 只有数据，全部补上 attackInterval；50 只配了 ultimateGain（8 只 atk<60 杂兵无奥义）；greenSlime/magicDragon 原有值保留。node --check 通过、vm 加载验证。version 2.10.22。
