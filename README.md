## 背包布局

在“我的背包”棋盘右侧使用“保存布局”和“应用布局”。最多保存 5 套，保存武器类型、数量、位置与旋转；选择槽位可预览，覆盖与删除需要再次确认。

布局保存在当前浏览器的本机存储中，可跨游戏存档与重新开局复用；清除网站数据会删除布局，不会随游戏存档同步到其他设备。应用时只使用当前持有的真实装备，重复武器按件匹配。缺少的装备、涉及未解锁格子的整件装备、越界或冲突的位置都会跳过，并显示对应件数及去重后的未解锁格数；未应用的已有装备收回待放置区，不会出售或消失。保存空背包不会覆盖已有布局。

应用操作继续使用原有 `bp` 增量录像格式，回放无需读取本地布局，也不消耗游戏随机数。
