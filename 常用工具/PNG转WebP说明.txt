PNG 批量转 WebP

启动：双击同目录的「PNG转WebP.bat」。当前电脑已经具备所需依赖。
支持 Windows 高 DPI 缩放，字体、窗口和间距按显示器缩放比例绘制。
更新工具后需要关闭旧窗口，再重新启动才能启用高 DPI 模式。

1. 选择含 PNG 的输入文件夹。
2. 输出默认放到输入文件夹的 webp_output，也可另选文件夹。
3. 默认包含子文件夹、使用无损压缩、跳过已有同名 WebP。
4. 点击「开始转换」，结束后点击「打开输出文件夹」。

子文件夹结构、文件名、图片尺寸和透明背景会保留；源 PNG 不会删除。
无损模式适合魔塔像素素材，保持 8 位 RGBA 像素。
有损模式可调质量 0–100，默认 85，质量越高通常体积越大。
转换后体积可能大于原 PNG；窗口会统计实际体积变化。
失败文件会列入日志，其他图片继续转换。停止按钮在当前图片完成后停止。
动画 PNG 暂不支持，会记为失败，不会只导出第一帧。
高位深 PNG 会转换为 8 位 RGBA；文本等 PNG 专属元数据不保留。
该工具只转换文件；若用于游戏，请自行更新图片引用为 .webp。

依赖：Python 3.9 或更高版本（含 tkinter），以及支持 WebP 的 Pillow。
在其他电脑缺少 Pillow 时，运行：python -m pip install --upgrade Pillow

命令行用法（在本目录打开终端）：
python png_to_webp.py "D:\图片"
python png_to_webp.py "D:\图片" -o "D:\输出" --lossy --quality 85

附加参数：
--no-recursive  仅处理当前文件夹
--overwrite     覆盖已有同名 WebP（默认跳过）
--help          查看帮助
